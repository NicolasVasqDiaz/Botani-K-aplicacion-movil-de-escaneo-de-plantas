# Botani-K-aplicacion-movil-de-escaneo-de-plantas
Botani-k es una aplicación móvil educativa que ayuda a jóvenes y estudiantes de Cajamarca a identificar, aprender y cuidar la flora endémica de su región, combinando inteligencia artificial con información botánica verificable, para generar conciencia ambiental y promover la conservación de las plantas locales.
